# agent-platform

Lokale Agenten-Orchestrierungsplattform: Linear-Tickets importieren und vollständig über ein lokales Kanban-Board bearbeiten — mit Claude-Planung, Codex-Implementierung, automatisierter Testphase und Claude-Review in begrenzten Rework-Schleifen.

> Diese README wird in der Abschlussphase vervollständigt (Architektur, Setup macOS/Linux/VPS, Sicherheitsmodell, Troubleshooting).

## Schnellstart

```bash
corepack enable
pnpm install
pnpm db:migrate
pnpm dev
```
